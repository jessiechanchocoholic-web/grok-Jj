# 07 試卷掃描＋自動清答案出卷王（補習中心專用 Web App）

## 專案簡介
為補習中心度身訂造嘅 **100% 免費、無浮水印、無限頁數、純本地運行** 試卷掃描與自動清答案工具，支援 iPhone / iPad Safari 即開即用（可「加至主畫面」變成獨立 PWA App）。

- **線上即開即用網址**：[https://jessiechanchocoholic-web.github.io/grok-Jj/scanner/](https://jessiechanchocoholic-web.github.io/grok-Jj/scanner/)
- **源碼目錄**：[`/scanner`](../../scanner/) 及 [`./app`](./app/)

---

## 核心功能
1. **四大匯入途徑（相片＋舊作業 PDF 通殺）**：
   - **📷 即時影相掃描**：直接開手機 / iPad 後置鏡頭連續拍攝多頁學生功課、評估、小測。
   - **📄 匯入舊作業 PDF（自動拆頁清答案）**：內置本地 `pdf.js` 引擎，揀選之前有答案嘅 `.pdf` 作業檔，即刻自動拆開每一頁做高解析度渲染，一鍵清走彩色/手寫答案再重新合併出乾淨 PDF。
   - **🖼️ 相簿多選相片**：一次過由相簿揀幾十張拍好嘅試卷相片。
   - **✨ 載入「試用示範卷」**：內置逼真 P3 英文評估示範卷（連手機陰影、藍筆手寫答案、紅筆 88 分同剔號、鉛筆草稿字、頂部校名同學生名），一開即刻睇到清理前後對比。

2. **三大智能「清答案 ＆ 遮私隱」濾鏡 + 去黑影漂白**：
   - **⚡ 超級一鍵全清**：一撳即刻同時執行去紅藍筆、去鉛筆草稿、去黑影漂白、遮蓋頂部校名及學生姓名，並套用到全卷所有頁數。
   - **🔴🔵 自動去紅筆批改／藍筆手寫答案**：透過色相與飽和度（Chroma/HSV）＋1px 邊緣抗鋸齒消除演算法，一秒洗白老師紅筆剔號、交叉、分數同學生藍筆/彩筆答案，同時保護深黑印刷題目同填充橫線（`____`）。
   - **☀️ 自動去黑影＋紙底漂白加深**：局部背景估算（Adaptive Background Bleaching），將手機影相嘅灰暗紙底同枱面陰影完全變做純白 `#FFFFFF`（大幅節省打印機墨水），並加深黑色印刷字體。
   - **✏️ 濾走淺色鉛筆字／草稿筆記**：自動區分淺灰鉛筆筆跡與深黑印刷字體，支援靈敏度滑桿即時預覽。
   - **🛡️ 一鍵遮頂部學校名＋學生姓名**：自動用白框遮走試卷頂端嘅學校名、學生名、班別（可微調遮蓋高度百分比）。

3. **手動觸控精修工具（支援手指 ＆ Apple Pencil）**：
   - **⬜ 拉白框遮答案**：一拉即遮走深黑印刷答案、學校校徽或指定區域。
   - **🖌️ 塗改液筆**：自由塗抹擦白頑固筆跡（可調筆刷粗幼）。
   - **📏 補劃填充橫線 (`____`)**：如果擦答案時順手擦走咗條橫線，一拉即刻補返條水平黑線俾學生寫字。
   - **↩️ 復原上一步 / 🗑️ 清除手塗**。

4. **多頁管理與一鍵出 A4 PDF / AirPrint 直接列印**：
   - 支援頁次前後調換、複製頁、刪除頁、一鍵套用同一設定到全部頁。
   - 按年級（P1–P6）同科目（中／英／數／常識人文）自動命名檔案（如 `P3_英文_空白練習卷_2026-10-24.pdf`）。
   - **⬇️ 即時下載乾淨 A4 PDF**：純本機合成標準 A4 PDF，完全唔經外部伺服器，100% 保障學生私隱。
   - **🖨️ 直接列印 (AirPrint)**：內置 `@media print` 滿版 A4 排版，iPad / iPhone 直接連中心打印機即印。
