## v2.0 實戰重點升級（針對 3 小時手機大量連拍需求）
1. **預設 0 頁乾淨起動＋100% 隨時刪除與清空歸零**：
   - 一打開 App 預設為 **0 頁空白乾淨狀態**，絕無任何範例頁阻住出卷。
   - 每一頁（包括手動撳「✨ 載入 1 頁測試範例」）都可隨時撳 `🗑️` 刪除，或撳 **「🗑️ 清空全部重設 (歸零)」** 徹底變返 0 頁並清走本機暫存。
   - 若曾載入測試範例，一旦匯入真實相片或 PDF，系統會自動移除測試範例，保證唔會混入正式試卷。
2. **積分圖 (Integral Image) 極速引擎（提速 5 倍，單頁處理 ~80ms）＋ IndexedDB 自動防走失存底**：
   - 改用 O(1) 積分圖局部背景估算及 256 級對比度 Lookup Table（LUT），加上底層濾鏡快取（手塗白框/塗改筆 0ms 即時重繪，唔重算濾鏡），手機連續影幾十張依然順滑如絲。
   - 內置瀏覽器 **IndexedDB 自動存底**：每影一張相即刻鎖定存入本機，就算中途電話響或 Safari 重新載入，一開返全部原圖底都仲喺度。
3. **永久鎖定「Original 原圖留底」＋「已清答案學生版」雙版本同步輸出**：
   - 每一頁永遠獨立保存 **版本 A：Original 原圖留底** 同 **版本 B：已清答案學生版**（隨時撳「🔄 還原此頁原圖重做」即可 100% 變返剛影低嘅原圖，唔使重新影過）。
   - 底部提供三大下載按鈕：
     - **⚡ 同時下載「兩個版本 PDF」（Original原圖 + 清答案版）**：一撳即刻自動下載兩份 PDF（`*_Original原圖留底.pdf` + `*_已清答案學生版.pdf`），趕時間影低留底最安心！
     - **📷 只下載 Original 原圖留底 PDF**（方便日後隨時再放入「📄 匯入舊作業 PDF」慢慢執）。
     - **✨ 只下載已清答案學生版 PDF**（或 **🖨️ AirPrint 列印** 直接印俾學生做）。
