### 2. 技術架構與後端拆解（由 `honjitsujapan.com` 源碼逆向發現）
1. **前端與跨平台封裝**：
   - 實際核心係一套高度優化嘅 **Web App (`/app.html`) + Capacitor / WKWebView 原生外殼**，所以能夠同時支援 iOS、iPadOS、Android（`PLAY_LIVE` 準備中）及網頁版深層連結（Universal Links `/e/*`）。
   - 配色系統（取自其 CSS `:root`）：
     - 淺色模式：米白底 `#F7F5F0`、卡片 `#FFFEFB`、主深藍 `#1F3049`、次文字 `#6F6A5E`、邊框 `#E4E1DA`、珊瑚紅強調色 `#C33C2E`
     - 深色模式：深灰底 `#16171A`、卡片 `#1F2126`、文字 `#ECEAE4`、強調色 `#E25A4C`
2. **伺服器與資料庫**：
   - **Cloudflare Pages + Cloudflare Workers (`_worker.js`)**：負責動態注入 SEO JSON-LD（`Schema.org/Event`）、OpenGraph 分享卡圖片（`/img/{id}/card-zh.jpg`）及 `/tokyo/today` 等分類指南頁。
   - **Supabase (PostgreSQL + Auth + Storage)**：儲存活動資料庫、用戶登入後嘅多裝置同步行程、收藏與同行者協作。
3. **外部 API 整合**：
   - **天氣數據**：Open-Meteo API（CC BY 4.0，傳送約 1km 範圍座標查詢即時天氣與預警）。
   - **地圖與路線**：Apple MapKit（顯示地區圈圈活動數量 Cluster）+ Google Maps Places（輸入酒店住宿與計算點對點交通時間）。
   - **密碼安全**：Have I Been Pwned（k-anonymity 前 5 位 SHA-1 雜湊驗證）。
4. **每日活動情報來源**：
   - 自動化爬蟲每日抓取東京及關東各大官方觀光網、美術館/博物館官網、PR TIMES 新聞稿、祭典/花火大會官網公開頁面，再用多語系翻譯管線轉成**繁體中文（港/台用詞）、日文、英文**，並保留日文原名與官方連結。

### 3. 「本日東京」10 張 App Store 截圖核心畫面拆解
1. **主頁（活動探索）**：頂部搜尋＋「今天」掣 ➔ 橫向滑動日曆膠囊 ➔ 分類圓角掣（全部/藝術/市集/祭典/美食/動漫）➔ 互動地圖（深藍圓圈數字標示各區活動數量）➔「近期熱門・季節特輯」橫向卡片 ➔ 右下角懸浮紅色「已收藏 N」掣。
2. **活動詳情頁**：大圖橫幅＋分類標籤 ➔ 繁中標題＋原文副標題 ➔ 紅字標籤資料格（日期、時間、場地、地址、距離/交通時間、最近車站、票價、惡劣天氣安排）➔ 底部固定「加入行程 / 已在行程」＋收藏心心＋分享掣。
3. **一按製作活動分享圖**：自動將活動相片、日期、地點、票價與 App Icon 合成精美長圖，一撳「傳送」或「複製圖片」發畀朋友。
4. **大家想去哪裡？一起投票決定**：共享行程入面嘅投票池，旅伴撳「想去」，票數最多自動排最前並標示「最多人想去」，決定好一撳「排入行程」。
5. **和朋友一起編排行程**：共用同一個時間軸，自動計算活動與酒店之間嘅交通時間。
6. **以連結分享行程**：生成唯讀行程連結（如「週末兩日遊」），朋友打開即可一鍵複製到自己行程。
7. **活動卡收集冊（Gamification 遊戲化）**：去過嘅活動變成黑底金邊紀念卡，到達現場自動蓋上紅色「来場 VISITED」印章，更有機會抽中「金卡」或「黑金 1%」稀有卡並為活動評分。
8. **旅程結束自動生成回顧影片**：將多日走過嘅路線（D1、D2、D3...）與活動串成地圖軌跡短片。
9. **iOS 主畫面小工具 (Widgets)**：大、中、小三款桌面小工具顯示出發倒數、當日行程與 7 日天氣。
10. **iPad / 雙螢幕並排檢視**：橫放時左邊地圖/列表、右邊活動詳情並排顯示。
