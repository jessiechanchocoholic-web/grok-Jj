# 04 總題庫同出卷

**狀態：** 骨架建立中，等另一間學校課本
**開始：** 2026-10-22

## 目標
以愛秩序灣官立小學課程（年級／科目／單元）做骨架，整合幾間學校嘅課本、工作紙、試卷同答案，做一個總題庫，供：
1. 溫習闖關遊戲（越嚟越豐富）
2. 一鍵出卷 app（離線、手機電腦都用到，出試卷＋答案卷）

## 計劃
1. 盤點已有資料，建立 curriculum 骨架 ✅
2. 收另一間學校課本 → 對照映射到愛秩序灣單元（科學、人文、中文同出版社；英數要逐課對）
3. 入題（自擬題，標 source/verified）
4. 遊戲接題庫；開發一鍵出卷 app（交 PM Bot 分派）

## 資料位置
- 私人 repo（有版權原材料＋資料庫）：https://github.com/jessiechanchocoholic-web/question-bank
- 公開 repo 唔放課本原文或掃描。

## 仍欠
- 數學 P1 一上A/B 目錄；P2 L12–17、P5 L11–13 課名
- 人文 P1、P2、P5 目錄
- 科學 P4 L6–8、P5 L6–7 課名
- 中文各課詞語表、寫作單元內容
- 數學、科學出版社名稱確認
- 愛秩序灣教學進度表（每學期教邊啲單元）
- 另一間學校課本、各校工作紙／試卷／答案
