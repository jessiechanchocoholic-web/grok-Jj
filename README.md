# grok-Jj 多 Bot 專案團隊

本 repo 是多 Bot 協作專案的單一事實來源（SSOT）。所有任務、決定、交接都記錄在 `docs/ssot/`，任何 AI 平台或成員都可依此接手。

## 團隊角色
| 角色 | 職責 |
|---|---|
| Jessie（專案負責人） | 設定目標、審批重要決定、驗收成果 |
| 專案經理 Bot | 分派與追蹤任務，維護 STATUS.md |
| 開發 Bot | 撰寫程式碼、開分支及 PR |
| QA Bot | 測試與同儕審查 |
| 安全 Bot | 審查權限、機密資料、依賴套件；高風險問題直接上報 Jessie |
| 文件 Bot | 維護 README、skills 與日誌 |
| 部署 Bot | 版本管理、發佈檢查清單；部署須經 Jessie 批准 |

## 工作流程
1. 專案經理 Bot 建立任務並分派（STATUS.md）
2. 開發 Bot 開分支並提交 PR
3. QA Bot 測試與審查
4. 安全 Bot 審查
5. 部署 Bot 準備發佈
6. Jessie 批准後才部署／合併重要變更
